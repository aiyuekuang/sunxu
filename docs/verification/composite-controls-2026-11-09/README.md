# 组合控件验收 · 2026-11-09

## 检查范围

- 示例路由：`examples/catalog` → 底部“地图图表”页签。
- 环境：Expo Web，亮色主题，Chromium；三个视口分别为 375×812、320×720 和 812×375 CSS px。
- 检查组件：`DialPad`、`AudioPlayer`。
- 交互：输入 `1`、`2`，删除末位并提交 `1`；切换示例音频为播放中。

## 结果

| 视口 | DialPad 外框 | 单键 | AudioPlayer | 横向溢出 |
|---|---:|---:|---:|---|
| 375×812 | 351×451 | 109×64 | 351×119 | 无 |
| 320×720 | 296×451 | 91×64 | 296×119 | 无 |
| 812×375 | 788×451 | 255×64 | 788×119 | 无 |

播放器的播放按钮视觉区域为 40×40dp，扩展触控目标为 48×48dp；拨号按键和删除/提交按钮为 64×64dp。Catalog 主内容区可纵向滚动。812×375 下，滚动后删除按钮可见；继续滚动后播放器整体及播放按钮均完整位于视口内。

DOM 几何、内部滚动区尺寸、交互结果和页面异常记录见 [`geometry.json`](./geometry.json)。
